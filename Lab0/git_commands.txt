1.git clone- создаёт локальную копию удалённого репозитория по указанному URL. Часто используется для начала работы над чужим проектом. 
2.git status- показывает текущее состояние репозитория: какие файлы изменены, но не добавлены в индекс, какие ожидают коммита, есть ли неотслеживаемые файлы.
3.git add- добавляет изменения из рабочего каталога в индекс
4.git commit- эта команда фиксирует изменения в локальном репозитории.
5.git push- эта команда отправляет локальные коммиты в удалённый репозиторий, делая изменения доступными для других участников команды. 
6.git init- инициализирует новый Git-репозиторий в текущей папке.
7.git log- выводит историю коммитов в хронологическом порядке (от новых к старым).
8.git branch- создаёт новую ветку с указанным именем.
9.git checkout- переключает вас на указанную ветку и загружает её состояние в рабочий каталог.
10.git merge- объединяет указанную ветку с текущей.
