1.Git — это распределённая система контроля версий. Git решает несколько ключевых задач, возникающих при работе с изменяющимися файлами (кодом, документацией, дизайном и т. д.).

2\.Централизованные системы контроля версий: в таких системах каноническая история проекта хранится на единственном сервере. Разработчики получают рабочую копию с локального компьютера, вносят изменения и отправляют их обратно на центральный сервер. Распределенные системы контроля версий: здесь у каждого разработчика есть полная локальная копия всего репозитория, включая всю историю изменений. Это позволяет работать в автономном режиме, а синхронизировать изменения с другими участниками — по мере готовности.

3\.Репозиторий в Git — это хранилище, в котором содержатся все файлы вашего проекта и вся история их изменений.
